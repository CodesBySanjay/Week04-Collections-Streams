## 🧾 Overview

This week, we dive into Java Generics for type safety, explore the Collections framework to manage groups of objects, and understand Java IO streams for input/output operations. We also cover Exception handling, regular expressions, unit testing with JUnit, and Java 8 features like lambdas and streams.

---

## 📌 Topics Covered

### 01 - Java Generics

- Introduction to generics for type-safe collections and methods
- Generic classes and methods usage

### 02 - Collections

- Overview of Collection interfaces and classes: List, Set, Map
- Working with ArrayList, HashSet, HashMap, and more

### 03 - Java IO Streams

- Reading and writing files with streams
- Using BufferedReader, FileReader, InputStreamReader

### 04 - Exceptions

- Exception types and handling
- Try-catch-finally blocks and custom exceptions

### 05 - Regex & JUnit

- Pattern matching and regular expressions basics
- Writing unit tests with JUnit framework

### 06 - Java 8 Features

- Lambda expressions and functional interfaces
- Stream API for collection processing
- Method references and default methods
